# Placewell Media images

Public image hosting for Know Buckhead emails and posts.

- **Images only.** This repo is public: never commit code, API keys, tokens, subscriber data or anything private.
- **Permitted images only:** our own photos, venue-provided photos used with permission, or our own graphics.
- Layout: `images/<issue>/<file>.png` (for example `images/issue-07/hero.png`); test files live in `images/test/`.
- Link format for emails: `https://raw.githubusercontent.com/TheYungStump/placewell-media/main/images/<issue>/<file>`
